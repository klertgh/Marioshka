# Marioshka

Учебный 2D-платформер на C++ в стиле Mario. Игрок перемещается по уровню, прыгает по платформам, собирает монеты и встречает врагов

## Возможности

- Анимации бега, прыжка и покоя персонажа
- Физика движения и столкновений на Box2D
- Сбор монет со счётчиком на экране
- Враги, которых можно победить прыжком сверху; другие столкновения с ними приводят к проигрышу
- Камера, следующая за персонажем
- Пауза и перезапуск после проигрыша
- Загрузка уровня из изображения `map.png`

## Технологии

- C++
- SFML 2.6.1 — графика, окно и ввод
- Box2D 2.4.1 — физика

## Сборка и запуск

В текущем проекте зависимости настроены для **Debug | x64**. Пути к библиотекам абсолютные: на другом компьютере их нужно изменить.

1. Установите Visual Studio 2022 с компонентами разработки классических приложений на C++ и Windows SDK.
2. Подготовьте SFML 2.6.1 для Visual C++ 2022, 64-bit, и Box2D 2.4.1, собранную для x64 Debug.
3. Откройте `mario3.sln` и выберите **Debug | x64**.
4. В свойствах проекта для этой конфигурации укажите свои пути:
   - **C/C++ → Общие → Дополнительные каталоги включаемых файлов**: каталог `include` SFML и каталог `include/box2d` Box2D, содержащий `box2d.h`.
   - **Компоновщик → Общие → Дополнительные каталоги библиотек**: каталог `lib` SFML и каталог с Debug-библиотекой `box2d.lib`.
5. В разделе **Отладка → Рабочий каталог** укажите `$(ProjectDir)`: игра ищет ресурсы относительно рабочей папки.
6. Соберите и запустите проект сочетанием **Ctrl+F5**.

Настройки линковщика для статической Debug-версии SFML и определение `SFML_STATIC` уже записаны в проекте. Сборка требует совместимых версий и архитектуры библиотек.

Если запускаете собранный `.exe` отдельно, положите рядом папку `textures`, файлы `map.png` и `font.ttf`, а также необходимые DLL используемых зависимостей. Запускайте из этой папки.

## Управление

| Клавиша | Действие |
| --- | --- |
| A | Движение влево |
| D | Движение вправо |
| W | Прыжок с поверхности |
| Esc | Включить или снять паузу |
| Пробел | Начать заново после проигрыша |

## Структура проекта

| Файлы | Назначение |
| --- | --- |
| `main.cpp` | Создание окна и игровой цикл |
| `Game.*` | Инициализация, обновление, интерфейс и перезапуск |
| `Mario.*` | Персонаж, управление и обработка столкновений |
| `Enemy.*`, `Coin.*` | Враги и монеты |
| `Physics.*` | Физический мир Box2D |
| `Map.*` | Построение уровня из изображения |
| `Camera.*`, `Renderer.*` | Камера и отрисовка |
| `Animation.*`, `Resources.*` | Анимации и ресурсы |
| `textures/`, `map.png`, `font.ttf` | Текстуры, карта и шрифт |
